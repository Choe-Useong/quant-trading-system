# 기능 목록

데이터 수집부터 전략 계산, 검증, 실매매 운영까지 코드로 구현된 기능을 정리했습니다.

## 1. 데이터 기능

- 가격 데이터 수집 및 갱신
- 거래량·거래대금 데이터 수집
- 국내 주식 시가총액 데이터 구축
- 국내 ETF 목록·카테고리·가격 데이터 구축
- 환율 및 원화 환산 가격 반영
- 전략 계산용 wide cache 생성
- 연구용 캐시와 실매매용 캐시 분리
- 신호 계산 가격과 거래·평가 가격 분리
- 가격 존재 여부 기반 상장 가능 구간 처리

## 2. 전략 계산 기능

- 설정 파일 기반 feature graph 실행
- 가격, 거래량, 거래대금, 시가총액, 외부 지표 기반 feature 계산
- 수익률, 이동평균, 이동표준편차, 변동성 백분위 계산
- 횡단면 랭킹과 랭크 백분위 계산
- 월별 평균, 월별 합산, 스킵 구간 모멘텀 계산
- 기간별 계산값 유지
- 조건 비교 기반 필터 feature 생성
- 시장 breadth 계산
- 시장 기준 feature 참조
- 여러 feature의 가중 합산

## 3. 유니버스 및 필터 기능

- 허용 종목 목록 기반 필터링
- 상장 기간 기준 필터링
- 시장 구분 기준 필터링
- 시가총액·거래대금 등 rank 기반 필터링
- feature 값 기준 필터링
- ETF 카테고리 기반 필터링
- 상관 기반 중복 노출 축소

## 4. 목표 비중 생성 기능

- 상위 N개 자산 선택
- 동일 비중 생성
- 고정 비중 생성
- 순위별 고정 비중 생성
- 상장 자산 대상 고정 비중 생성
- feature 값 기반 비중 생성
- HRP 비중 생성
- 군집 동일 비중 생성
- 전체 노출 비율 조절
- 방어자산 전환
- 목표 비중 변경 시점 중심 출력

## 5. 백테스트 및 검증 기능

- 그리드 백테스트
- 횡단면 백테스트
- Walk-forward 검증
- PBO 분석
- SPA 검증
- StepM 검증
- 벤치마크 대비 초과성과 분석
- 최대낙폭과 회복기간 분석
- 전략 결과 DB 구축 및 조회
- 전략 선호도 설문 기반 점수화

## 6. 실매매 기능

- Preview 모드와 live 모드 분리
- 목표 비중 기반 주문 계획 생성
- 주문 제출 전 계획 저장
- 체결 확인
- 상태 파일 기록
- 계좌 스냅샷 저장
- 텔레그램 알림
- 스케줄러 기반 실행
- 활성 전략 프로필 전환
- 수동 매매 이후 현재 보유 기준 재계산
- pending state 기반 중복 실행 방지
