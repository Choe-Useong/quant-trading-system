# 기능 목록

**확인 기준: 2026년 11월 20일**

데이터 수집, 전략 계산, 백테스트, 탐색·검증 및 자동매매 기능을 구현 범위별로 정리하였다.
기능 설명은 전체 프로젝트 기준이며, 공개 저장소에는 이 중 일부 코드만 포함되어 있다.

## 1. 데이터 수집과 준비

- **시장 자료:** 업비트 현물, 국내 주식·ETF, 미국 ETF의 가격·거래량 수집과 갱신. 시가총액·업종·보통주 구분·ETF 분류·환율·재무 캐시 구성.
- **국내 주식 가격:** KRX 정규장 종가와 KRX 기준가 수정계수로 수정주가 산출. 상장폐지 종목 포함.
- **재무 시점:** 연간 공시의 접수일을 이용하여 거래일 기준 이용 가능 시점을 반영. 정정공시·항목별 결측은 자료별 처리 규칙 적용.
- **무위험수익률:** 미국 3개월 국채(DTB3)·CD 91일물 금리 일별 자료.
- **계산용 캐시:** 시각×종목 형태의 가격·피처 입력 구성. 연구·라이브 캐시, 신호 가격·체결 가격·평가 가격 구분.
- **바이낸스 선물:** 거래가격 OHLC·거래량·USDT 거래대금·마크가격·펀딩 수집. 공식 아카이브 종목 탐색, 다운로드 계획, 병렬 다운로드, 체크섬 확인, 기존 파일 재사용 및 캐시 병합.
- **결측 복구:** 불완전 관측 캐시 저장 후 캔들·펀딩 재수집. 누락·충돌·보충 이력 기록 및 연구용 데이터 정책 적용.
- **Hyperliquid:** 시장 지표·계정 순위·상위 계정 포지션의 현재 스냅샷 수집, 시간별 실행, 원본 보관·월별 압축. 연구용 관측 수집 단계이며 과거 누락 시점의 소급 복원은 지원 범위에 포함하지 않는다.

## 2. 피처 계산

- **계산 그래프:** 설정 파일로 원천 자료와 연산 의존성을 정의하고 필요한 피처를 순서대로 계산.
- **가격·거래량 지표:** 단순·지수·거래량 가중 이동평균, 단순·로그수익률, 이동 합계·최대·최소·표준편차, 변동성 및 상대 거래량.
- **순위·분위:** 종목 간 순위·백분위, 과거 분포 대비 백분위, 그룹 내 순위, 그룹별 집계.
- **기간 집계:** 일·주·월별 집계, 최근 구간 제외 모멘텀, 기간 시작값·계산값 유지.
- **시장 기준:** 시장폭(확산도), 특정 자산의 지표 참조, 롤링 베타, 상태에 따른 피처 선택.
- **조건·상태:** 비교·AND·OR·NOT, 진입·청산 조건, 보유 유지, 최대 보유 봉 수, 재진입 대기.
- **신호 정렬:** 피처·필터·매매 신호의 지연을 별도로 지정.

## 3. 종목 선정과 목표 비중

- **투자 대상 필터:** 허용·제외 종목, 상장 기간, 시가총액·거래대금·지표 순위, ETF 분류·업종 및 지표값 조건.
- **선행 종목 선별:** 지정 주기에 유동성 등으로 투자 대상을 갱신하고 후속 계산 범위 축소. 그리드·PBO·SPA·워크포워드에 선별 기록 연결.
- **그룹·롱숏 구성:** 여러 지표의 분위 교차 분류, 롱·숏별 조건·순위·편입 수 및 목표 노출 배분.
- **보유 종목 관리:** 청산 조건까지 기존 종목을 유지하고 빈자리만 신규 후보로 충원. 최대 보유기간·재진입 대기 설정.
- **배분 방식:** 동일 비중·고정 비중·순위별 비중·계층적 위험균등배분(HRP)·군집 동일 비중·지표 기반 종목별 비중.
- **전체 규모 관리:** 지표에 따른 전체 노출 배율, 방어자산 전환, 공분산 기반 포트폴리오 목표 변동성 배율.
- **헤지:** 지정 자산을 이용한 목표 노출 상쇄. 고정 배율 또는 롤링 베타를 이용하여 헤지 비중 계산.
- **수량 유지:** 목표 변경 시에만 주문을 전달하고 이후 수량 유지. 포트폴리오 전체 또는 종목별 변경 범위 선택.
- **다전략 결합:** 전략별 목표 비중을 배분 배율로 결합하여 공통 계좌의 순포지션으로 실행.

헤지는 산출한 목표 비중을 기준으로 계산한다. 다전략 결합은 Numba 선물 엔진의 그리드·PBO·SPA·워크포워드 경로를 지원하며, 종목이 겹치고 요청 시각이 다르면 마지막 목표 비중을 합산하는 근사가 적용된다.

## 4. 백테스트 엔진과 포지션 관리

| 엔진 | 구현 범위 |
|---|---|
| VectorBT | 현물 목표 비중 기반 백테스트, 거래비용·벤치마크·거래 가능 여부 처리 |
| Freqtrade 연동 | 기존 목표 비중을 선물 주문으로 변환하고 라이브러리의 체결·펀딩·증거금 계산과 연결 |
| Numba 선물 | 다종목 USDT 선형 무기한 선물, 공통 현금, 포지션별 격리증거금 또는 계좌 전체 교차증거금, 종목별 롱·숏 순포지션, 시장가 |

- **장부·주문:** 공통 자산 스냅샷 기반 수량 산정, 수량·가격 단위와 최소 주문 검사, 자금 부족 거부·대기·재시도 기록.
- **비용·위험:** 수수료·슬리피지·종목별 펀딩 일정·유지증거금 구간·강제청산·최종 정산 반영.
- **보유 중 조절:** 첫 체결 이후 최대 보유시간, 지표 조건에 따른 일부 청산, 실제 계좌 대비 포지션 노출 상한. 롱·숏별 조건과 축소 비율 지정.
- **데이터 처리:** 거래 가능 기간, 보유 중 필수 가격, 상장폐지 정산 및 연구용 결측 처리 내역 기록.
- **후보 평가:** 공통 입력 준비를 재사용하고 독립 후보별 상태를 분리하여 병렬 평가. 동시 실행 수·이벤트 수·메모리 추정 예산 제한.

Numba의 격리증거금은 마크 시가 또는 마크 OHLC 청산 모형을 사용한다. 교차증거금은 계좌 전체의 마크 시가 판정을 지원한다. 자동 증거금 추가·격리/교차 혼합·교차 봉중 청산·지정가·봉중 손익절 주문은 구현 범위 밖이다.

## 5. 탐색과 자동 전략 조립

- **기존 설정 탐색:** 같은 그리드 설정에서 전수·랜덤·TPE 방식 선택. 탐색 횟수·시드·예산 지정과 평가 이력 저장.
- **전략 조립:** 등록한 피처를 재료로 비교 조건과 논리식을 생성하고 진입·청산·보유 상태·롱숏 규모를 하나의 전략으로 구성.
- **조합 제한:** 연속·이산 파라미터 범위와 간격, 규칙·조건 수·논리 깊이·최대 노출 설정.
- **생성 단계 검사:** 기간 역전, 중복·모순 조건, 진입이 항상 청산을 동반하는 규칙 검사.
- **목적함수:** 수익률·Sharpe·Sortino·Calmar·Martin·IR 등 선택, 지표 가중합, 별도 Python 평가함수 등록.
- **선택 제약:** 최소 거래 수·최대 낙폭을 탐색 제약으로 전달하고 충족 후보 중 최종 전략 선택.
- **실험 재개:** SQLite 평가 기록, 유효 평가 수와 생성 시도 수의 구분, 설정·입력·코드 식별 정보 대조.
- **기간 분리:** 학습 구간에서 탐색하고 별도 평가·테스트 구간에서 후보 확인.

전략 자동 조립은 단일 시장과 등록 피처 문법을 대상으로 한다. 일반 수식의 무제한 생성, GP·강화학습 기반 전략 발견은 별도 확장 범위이다.

## 6. 통계 분석과 성과 검증

- **백테스트 비교:** 횡단면·그리드 평가, 단일·복수 벤치마크, 초과수익률·정보비율·회귀 지표.
- **성과 지표:** 무위험수익률(고정 연율 또는 일별 금리 파일)을 반영한 Sharpe·수정 Sharpe·Sortino, 연 변동성, 추적오차, 젠센 알파·베타, 최근 3개월~5년 구간 지표.
- **성과 요인 분석:** 시가총액 가중 지수 재현과 공식 지수 대비 추적오차 측정, 브린슨 업종 성과 요인 분해(배분·선택·상호작용, 다기간 연결), 수익률 기반 스타일 분석.
- **워크포워드:** 이동·누적 학습, 학습·평가·이동 기간 지정, 평가 구간 시작 시 목표 복원, 구간 경계 수익률을 포함한 자산곡선 연결.
- **선택 편향 검증:** 양방향 CSCV PBO, SPA·StepM·MCS, 부트스트랩 기반 분석.
- **피처 연구:** 횡단면 IC·분위 수익률·순위 자기상관, 시계열 상관·회귀·표본 외 예측오차, 블록 부트스트랩·다중비교 보정.
- **위험·집중도:** 최대 낙폭·회복기간·미회복 구간, 연간 수익률, 종목·롱숏·상위 거래 기여도, 거래 손익과 계좌 손익 대사.
- **저장·조회:** CSV·Parquet, 대용량 결과의 경량 저장, 소형 분석표 자동 저장, 결과 DB 구축·검색, 전략 조합·불확실성 분석 및 선호도 점수화.

통계 검증은 설정된 후보군과 평가 구간에 적용한다.

## 7. 자동매매 운영

- **지원 시장:** 업비트 현물·국내 주식·미국 ETF의 목표 비중 기반 주문 계획과 실행.
- **실행 제어:** 미리보기·실주문 모드, 스케줄러 등록·활성화, 활성 전략 프로필 전환.
- **주문·기록:** 보유량 기준 주문 수량 계산, 체결 확인, 미완료 주문 상태를 이용한 중복 실행 차단, 원자적 상태 저장, 계좌 스냅샷·텔레그램 알림.
- **운영 확인:** 수동 거래 후 보유량 재조회, 거래소·종목 설정 확인, 캐시 갱신과 실행 결과 점검.

미체결·부분체결·취소 주문의 자동 복구와 주문 접수 직후 상태 기록의 공백은 보완 항목이다.

## 8. 정확성·재현성 점검 장치

- **정보 이용 시점:** 완료 기간 자료와 신호 지연, 공시 이용 가능일, 종목별 상장·거래 가능 기간 반영.
- **유효 구간:** 최초 유효 비중과 워밍업을 반영한 평가 시작, 백테스트·PBO·SPA·워크포워드 기간 처리.
- **입력 검사:** 시간축 순서·중복·유한값·필수 가격·계약 규칙 검사, 결측 대체·제외 내역 기록.
- **장부 검증:** 손계산 사례, Python·Numba 비교, Freqtrade 거래별 대조, 다종목 열 순서·동시 자금 배정·미래 구간 변경 검사.
- **변경 추적:** 실험 설정·비용·데이터 정책 기록, 결과 입력 식별 정보 저장, 확인된 결함과 재검증 상태 관리.
